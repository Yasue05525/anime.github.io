Правила группы и бота

Правила группы

1.1 - Запрещено любая оскорбление Создатель группы или администрации группы

1.2 - Запрещено ультраправых фашизм группе, так же распространение дезинформации, провокации, дискриминации, любая оскорбление связано с энтофолизмом (Ничтожество)

Правила использования бота

1.1 - Запрещено поведение использование команды для вызова негативного и неадекватного реакции для получения своих целях,все команды должны работать нормализации функции бота (ЧС - Временно)

Версия сайта (Beta-vers 0.007)

1.2 - Запрещено использовать дезинформацию распространение детского порнографии для жалобу на ботов, группе не допускается ультрафиолетового фашизма с отрицательным ответом против создатель бота, создатель не распространяется любая детская порнография все персонажы под возрастом ограничение, чтобы вызвать негативную и неадекватная реакции, карается Глобан (Система управление базами данных - Бесконечный ЗАПРЕТ)
