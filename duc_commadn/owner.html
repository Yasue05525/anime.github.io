Команда для разработчика

Список команды для разработчика и мастеров

1: .sudo global chat [peer_id] close [cause] (Запрещает любую команду через чат - Доступно для разработчика или Мастеров)

2: .sudo kick @[user_id] (Кикает любого пользователя без создателя чата - Доступно для разработчика)

3: Мей превратить мастера (Делает пользователя своих преемником - Доступно для создатель бота)

4: Мей уволить (Выгоняет из мастеров - Доступно для создатель бота)

5: Мей сохранить [вложении фотографии] (Сохраняет фотографии с помощью база данных JSON - Доступно для мастеров)

6: .sudo examination photo [ид фотографии] (Проверяет работает ли фотографии или нет - Доступно для разработчика)
